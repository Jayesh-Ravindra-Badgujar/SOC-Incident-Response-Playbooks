
# SOC Incident Response Playbooks

A Security Operations Center (SOC) documentation project demonstrating standardized incident response procedures, Indicators of Compromise (IOCs), MITRE ATT&CK mappings, and incident reporting templates for common cybersecurity incidents. This project follows the **NIST SP 800-61 Incident Response Lifecycle** and simulates real-world SOC L1 operational workflows.

---

## Features

- Incident Response Playbooks
- IOC (Indicators of Compromise) Reference
- MITRE ATT&CK Technique Mapping
- Incident Report Template
- Escalation Template
- Windows Security Event Reference
- Linux Authentication Log Reference
